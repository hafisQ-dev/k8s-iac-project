Terraform Registry:>
structure of main terraform file: 1.Provider(aws_provider and aws_region); 2.Virtual Network Layer(VPC(virtual private cloud),subnet,internet gateway,route table and route table assoc.) 3.Security Group(ssh and ingress and egress ports) 4.Server and Connections(AMI and EC2 Instances)
AWS Structure: 
[ AWS BULUT (eu-west-2) ]
 └── VPC (10.0.0.0/16) - Sana özel izole sanal veri merkezi  ###(cidr:Classless Inter-Domain Routing)
      ├── Internet Gateway - Sanal veri merkezinin internet vanası
      └── Subnet (10.0.0.0/24) - Sunucuların dizileceği mahal/blok
           ├── Security Group - Sunucuların önündeki firewall (Kapı Portları)
           ├── EC2: Master Node (k8s-master) - Kontrol düzlemi
           ├── EC2: Worker Node 1 (k8s-worker-1) - İş yükü sunucusu
           └── EC2: Worker Node 2 (k8s-worker-2) - İş yükü sunucusu
source types: resources(0'dan kaynak oluşturma(server,vpc,firewall rules et.)); data sources(var olana sorgu atma(aws_ami-ubnutu imajı çekme));list resource.
